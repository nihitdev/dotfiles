# Yazi

Arch Linux Yazi configuration with Catppuccin Mocha, Git status, fuzzy navigation, Markdown previews, and vendored plugins.

Install it with:

```sh
./install.sh --only yazi
```

Useful optional packages include `bat`, `fd`, `ripgrep`, `fzf`, `lazygit`, `glow`, and `ouch`. Run `ya pkg install` to restore plugin packages recorded in `package.toml`.
