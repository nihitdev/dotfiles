# Vendored and duplicated files

This repository keeps a small number of upstream assets in-tree so installed
configurations work without a package-manager update during setup.

## Yazi

`.config/yazi/plugins/` and `.config/yazi/flavors/` are generated by Yazi's package manager from
the revisions and hashes in `.config/yazi/package.toml`. Preserve each upstream license.
Update them with `ya pkg upgrade`, review the resulting code, and copy the
manifest, plugins, flavors, and licenses together.

The Catppuccin TextMate theme is intentionally present in both:

- `.config/bat/themes/Catppuccin Mocha.tmTheme`
- `.config/yazi/flavors/catppuccin-mocha.yazi/tmtheme.xml`

The applications require separate paths. The copies should remain byte-identical.

## Discord

`.config/discord/theme/system24.theme.css` and `.config/discord/theme/flavors/` are vendored
System24 distribution entrypoints. They retain upstream attribution and pin the
generated System24 CSS and GitHub-hosted assets to reviewed commits.

`.config/discord/theme/shellcord.theme.css` belongs to the separate Shellcord project.
Its generated CSS import is pinned here so an upstream branch update cannot
silently alter an installed theme.

## Update checks

Run:

```sh
python3 .config/scripts/validate_repo.py
```

The validator checks formats, local Markdown links, license presence, duplicate
theme equality, and mutable GitHub URLs in CSS.
